## Sobre

Estudante de Engenharia de Software na **UnB** (conclusão prevista jul/2028), atuo como
desenvolvedor freelancer construindo sistemas que ficam de pé em produção — não só
protótipo de curso. Gosto de pegar uma ideia que só existe no papel, entender como o
sistema atual realmente funciona por dentro e propor algo que gera mais lucro e mais
rentabilidade — não só automatizar por automatizar.

PT-BR nativo · EN intermediário · [contato.enzolf@gmail.com](mailto:contato.enzolf@gmail.com)
